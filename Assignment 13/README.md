# Assignment 13: Math Practice App

A browser-based math practice app for children aged 7–12: flip-card multiple-choice
questions in addition, subtraction, multiplication and division, with mistake tracking,
similar-question review and statistics. Built with React and TypeScript.

## Run it locally

```bash
cd "Assignment 13/math-practice-app"
npm install
npm run dev        # open the address it prints (http://localhost:5173)
```

`npm run verify` runs the linter, formatting check, all ~1,400 tests and the production
build. Full setup notes are in the [app README](math-practice-app/README.md#setup).
